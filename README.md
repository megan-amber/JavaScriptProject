# Project Name: Megan's Bank Management System

## Project Description
A personal webpage program using HTML, CSS, and JavaScript. Includes an About Me section, Featured Content,
Projects, and a Contact Form. Utilized JavaScript functions to dynamically interact with the webpage, create timed
content, and adjust styling elements, like adding a dark mode.

## Project Tasks
- **Task 1: Create the Structure**
    - Create a webpage with an about, projects, and contact section
    - Implement a personalized message at the top with the user's name
- **Task 2: Control Flow Implementation**
    - Add a featured content section that shows certain elements based on the number of projects
    - Add an Array that loops through different skills to feature in the about section
    - Add a dark mode feature
    - Display an alert message when the user submits the contact form
- **Task 3: Creating and Referencing DOM Elements**
    - Dynamically add a new section to the page using DOM methods
    - Modify existing elements in the CSS with selectors
    - Add a timed confirmation for form submissions
- **Task 4: Persistent Storage**
    - Replace the prompt from task 1 with a modoal window
    - Add a tooltip to the submit button
    - Save the user's dark mode preference
- **Task 5: Create Objects for Scalability**
    - Finalize the formatting of the output
    - Create project objects for each project
    - Dynamically render the projects to the screen
    - Create a ReadMe file

## Project Skills Learned
- OOP principles of Inheritance and Polymorphism
- Interaction with the DOM and utilizing selectors
- JavaScript used to connect front end and back end functions

## Language Used
- HTML for front end web development
- CSS for styling of the webpage
- JavaScript for webpage interactivity and dynamic elements
